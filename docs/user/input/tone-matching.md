同音词太多时，可以只保留指定声调的候选：在音节之后敲一个调号，候选随即按声调收窄。

声调输入缺省关闭：在「偏好设置 → 通用」（Windows 为「设置 → 通用」）勾选「用调号键按声调筛候选」打开；
也可在配置文件 `[general]` 分节里把 `tone_matching` 改为 `true`。大千注音自带声调键，该勾选框不可用。
macOS 与 Windows 保存后一秒内生效，无需重新切换输入法；Linux 没有设置界面，需改配置文件并重启青简服务。

## 调号

| 声调 | 键 |
|---|---|
| 一声 | `-` |
| 二声 | `/` |
| 三声 | `=` |
| 四声 | `\` |
| 轻声 | `.` |

调号敲在音节字母之后，属于它前面的音节：`zhidao=` 表示「道」读三声，候选只剩「指导」这类读音相符的词，
「知道」（四声）被排除；删掉调号，候选恢复原样。也可以混着敲：`ni-hao.` 给「好」标轻声，`-` 分隔音节的效果与 `'` 相同。

敲进去的调号会显示在拼音串里，一眼看得出标的是哪一声。

## 改调

一个音节后只留一个调号：连着再敲一个调号是**改**调，不是追加第二个。`ni-=` 显示为 `ni=`，
想换回别的调接着敲就行；退格一次即删掉整个调号，回到 `ni`。

## 规则

- 不敲任何调号时，输入与关闭声调输入时完全一致。
- 一个调号筛下来一个候选都不剩时，自动取消这一轮筛选，候选全部回来，不会出现打不出字的情况。
- 读音未收录的词不受调号约束，照常参与。
- 双拼同样可用：调号也敲在音节之后。注音模式的声调键（空格等）照常使用，并同样参与筛选。
- 打开后 `-` `.` 不再作为「输入含符号的英文串直接上屏」的入口，字母后紧跟这两个键时按调号处理。

## 与翻页键的关系

翻页键对可设为 `,` `.` 或 `-` `=`（「偏好设置 → 快捷键」）。设成这两组之一时，对应的键会先被翻页使用，
调号收不到：使用声调输入时请保留缺省的 `[` `]`。
