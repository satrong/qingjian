电脑没有麦克风时，可以拿手机当麦克风：手机浏览器打开一页表单，用手机自己的输入法说话，
文本会插进电脑上正在输入的那个文本框。手机上不需要装任何软件，网页也不需要麦克风权限——
语音由手机自己的输入法识别，青简只负责把文字从手机送到电脑。

## 打开

- **macOS**：菜单栏「青简 → 手机输入」打开开关，地址与二维码在「手机输入设置…」里。
- **Windows**：设置 → 手机输入，打开「开启手机输入」，下面那行地址复制到手机浏览器（隔空投送、微信文件传输助手都行）。
- **Linux**：在配置文件 `[remote]` 分节里把 `enabled` 改为 `true`，重启青简服务。

手机与电脑需连同一个 Wi-Fi。访客网络与手机热点通常隔离设备，连不上；连不上时先看电脑的防火墙提示
（第一次开启时系统会问是否允许青简接受传入连接，需要允许）。

## 在手机上说话

用手机浏览器打开那行地址，页面上有一个多行输入框：

1. 点输入框，切到手机自己的输入法，按它的麦克风说话；
2. 识别出的文字落进输入框，核对后点「发送到电脑」。

页面会显示结果：「已上屏」表示文本已经进了输入框；「已收到，光标可用时上屏」表示青简已经收到，
等电脑上有个能写字的地方再插上（多见于 Linux：输入法要在你动一下输入框时才有地方插）。
「令牌不对，请重新扫码配对」说明地址里的配对信息过期了，重新扫一次二维码或重新复制地址即可。

## 插到哪里

文本插进**最近用过输入框的那个窗口**，所以推送前先在电脑上点一下要写字的地方。几个边界：

- 密码框里不会插，青简也不接收这类推送；
- 正在组的拼音会被丢掉——手机来的是完整的一句话，不该插在拼音中间；
- 电脑上正在输入的拼音、候选窗口会一并收起；
- 一次推送只插一次；插上之后 30 秒内没人取（例如一直没在写字），这条文本作废。

## 关掉

macOS 菜单栏、Windows 设置里关掉开关，或把配置里 `[remote]` 的 `enabled` 改为 `false`，
青简便不再监听端口。同一局域网内的其他设备需要重新配对时，删掉配置文件里的 `token` 并重启，下次开启会生成新的。

## 安全

该功能只在本机开一个局域网服务，不经过任何服务器。同一网络内的其他设备可以访问这个端口，
所以青简用一枚配对令牌做门槛：地址里带着它，网页凭它提交，没有令牌的请求一律拒绝。
手机与电脑之间的内容是明文传输，公共网络下请勿使用。

改动配置后 macOS 与 Windows 一秒内生效，Linux 需要重启青简服务。
